## Objective

Build something practical.

Your task is to create a **Competitive Programming Style Submission Checker** using Bash.

It should:

- Generate test cases
- Run user solution
- Run reference solution
- Compare outputs
- Report exact failing testcase
- Show expected vs actual output
- Help users debug quickly

This is a real utility many developers use.
