# Resources

This folder contains reference material to help you complete the Bash prerequisite task.

## What You Should Learn

Before solving the task, be comfortable with:

### Shell Basics

- Variables
- Command substitution
- Exit codes
- Arguments

Example:

```bash
name="Alice"
echo "$name"
```

---

### File Operations

- Reading files
- Writing files
- Temporary files

Commands:

```bash
cat
touch
rm
cp
mv
```

---

### Conditionals

```bash
if [[ condition ]]; then
    ...
fi
```

---

### Loops

```bash
for i in {1..10}; do
    ...
done
```

---

### Functions

```bash
run_test() {
    echo "Testing..."
}
```

---

### Comparing Outputs

Useful tools:

```bash
diff
cmp
```

---

### Process Execution

Running external programs:

```bash
./solution < input.txt > output.txt
```
